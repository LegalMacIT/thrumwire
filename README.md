# thrumwire.com

The public website for Thrum, served free by GitHub Pages from this public
repo (LegalMacIT/thrumwire). Plain HTML and CSS; no build step.

- `index.html` — holding page for thrumwire.com
- `about/index.html` — About Thrum (thrumwire.com/about/)
- `style.css` — the Thrum "Mist" look (same colours as the app)
- `CNAME` — tells GitHub Pages to answer for thrumwire.com

The Thrum app itself (stories, settings, keys) lives in the private repo
LegalMacIT/Thrum. Nothing private belongs here: this repo is public.

Public wording is agreed with Hector in Thrum's `docs/about-thrum.md`.
